## About

Independent systems researcher and low-level software developer based in Indonesia. I work at the boundary between hardware, operating systems, and adversarial security—studying how systems execute, where trust assumptions fail, and how to engineer resilient tooling with minimal dependencies.

> Systems architecture is not merely about execution. It is the methodical design of resilient and secure communication pipelines.

- **Operating Philosophy:** Deterministic behavior, fail-closed boundaries, and zero unnecessary abstraction layers.
- **Primary Habitat:** Bare-metal and AArch64 environments, Linux internals, and Termux/Android mobile-first toolchains.
- **Research Mode:** Running a personal systems research lab at [daviddaryanto.my.id](https://daviddaryanto.my.id) focused on clean developer utilities, runtime analysis, and experimental security engineering.
